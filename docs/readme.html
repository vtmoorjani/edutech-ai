2. Architecture

[Landing] → [Multi-step Intake] → /api/skill-gap (Claude)
                                        ↓
                              [Skill Gap View] → /api/recommend (filter + Claude rerank)
                                                       ↓
                                       [Recommendations View] → user selects courses
                                                                       ↓
                                                            /api/roadmap (Claude)
                                                                       ↓
                                                              [Roadmap View] → save / PDF / share

Three Claude calls in the critical path. Each uses Zod-validated structured outputs and prompt caching on the skill taxonomy + filtered course slice. AI-generated course IDs are validated against the catalog before render to prevent hallucination.

Phase H — v0 follow-on changes (post-deploy) done

Shipped on the low-credit-balance branch via a Vercel v0 chat session, merged to main as PR #1 (commits 13a6be9..9091490). The branch name references the credit-balance error that surfaced during deploy, but the credit issue itself was not resolved here — see the errors log.

  • Auth refactor: Google OAuth replaced with email/password. New app/auth/login/page.tsx + app/auth/sign-up/page.tsx use supabase.auth.signInWithPassword() / signUp(). The OAuth callback route still exists but is no longer wired into the save flow.
  • Plans listing: new app/plans/page.tsx (index) and app/api/plans/route.ts (GET list). The MVP previously had no plan listing — only a single saved-plan view.
  • Plan management: app/api/plans/[id]/route.ts now supports PATCH (rename plan, update status: active / completed / archived) and DELETE; app/plans/[id]/page.tsx exposes inline name editing and status pills.
  • Save API refactor: gap field is now optional in /api/save; debug logging added; route reorganized.
  • Skill-gap prompt fix: capped at 20 gap entries to keep responses under the structured-output schema's max(20) limit.
  • Summary field expanded: SkillGapResult.summary Zod limit raised from 800 to 1500 chars; prompt now explicitly requests "concise overview (max 1500 characters)".
  • Roadmap save flow: bug fix to "Save my plan" on /roadmap.

Phase G — Feedback, analytics, a11y done

  • app/api/feedback/route.ts — auth-required thumbs + reason
  • components/feedback-widget.tsx — three-state widget on every recommendation card
  • lib/analytics.ts + components/analytics-provider.tsx — PostHog with no-op fallback
  • Funnel events: assessment_started, assessment_completed, recs_viewed, course_clicked, roadmap_built, roadmap_saved, pdf_exported, linkedin_copied, feedback_submitted
  • components/ai-disclosure-banner.tsx — dismissible amber AI disclosure
