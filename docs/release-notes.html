v0.1.0 — Initial MVP buildreleased

2026-05-08
Added
  • Landing page with the SkillPath AI value proposition and CTA to start the assessment
  • Multi-section intake form (/intake): current role, target role (pinned to AI Product Manager), years of experience, weekly hours, budget, timeline, preferred formats, desired outcomes, optional resume paste
  • Skill-gap analysis (/results): categorized breakdown of skills with current vs. target level and plain-language rationale; transferable strengths and adjacent-skill priorities
  • Course recommendations: ranked list across Coursera, Maven, Edureka, Udemy, LinkedIn Learning, Udacity, and Reforge with match scores and explainable "Why this / Why now / Tradeoffs / Ideal learner" panels
  • Phased learning roadmap (/roadmap): editable phase names and durations, capstone project suggestion, LinkedIn update suggestion
  • PDF export: roadmap downloadable as a Letter-size PDF with course list, objectives, and outputs per phase
  • Save flow: Google sign-in (Supabase OAuth) on "Save my plan", persists profile + skill gap + recommendations + roadmap
  • Saved plan view (/plans/[id]): read-only roadmap with PDF download
  • Feedback widget: thumbs up/down with optional reason on every recommendation
  • LinkedIn share: copy AI-generated LinkedIn post text + open LinkedIn share dialog
  • AI disclosure banner on every page (dismissible)
  • PostHog funnel events: assessment_started, assessment_completed, recs_viewed, course_clicked, roadmap_built, roadmap_saved, pdf_exported, linkedin_copied, feedback_submitted (no-ops gracefully when key unset)
  • Accessibility: skip-to-content link, semantic landmarks, ARIA labels on icon-only controls, visible focus rings, keyboard-navigable form
Architecture highlights
  • Three Claude (claude-opus-4-7) calls in the critical path — skill gap, recommendation rerank, roadmap — all using Zod-validated structured outputs and prompt caching on the taxonomy/catalog
  • Pre-filter (budget × time × gap-coverage) shrinks the catalog to the top 20 candidates before the rerank call to hold latency under the PRD's 5s NFR target
  • Hallucinated course IDs are filtered against the catalog before render — model can't invent courses
  • Supabase Postgres with Row-Level Security; reference tables (skills, courses, role mappings) are public-read, per-user tables (profiles, gaps, recs, roadmaps, feedback) are owner-only
Known limitations
  • Course catalog (25 entries) is structurally correct but every URL/price/rating is placeholder — needs human verification before public launch
  • Only the AI Product Manager target role is wired up in this MVP
  • LinkedIn share opens a dialog pointing at the SkillPath origin URL; per-roadmap public sharing requires a separate "share" table and is intentionally out of scope
Migration notes
  • Run supabase/migrations/0001_init.sql in the Supabase SQL editor to provision tables and RLS policies
  • Enable Google OAuth in Supabase → Authentication → Providers, with http://localhost:3000/auth/callback (and the production URL) in Redirect URLs
  • Set environment variables: ANTHROPIC_API_KEY (required), NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_ANON_KEY (required for save), NEXT_PUBLIC_POSTHOG_KEY (optional)

Versioning policy

  • MAJOR — breaking change to the user-facing flow, data model, or API contracts
  • MINOR — new feature or new target role/persona; backwards compatible
  • PATCH — bug fix, copy edit, accessibility tightening, infrastructure tweak with no user-visible behavior change
